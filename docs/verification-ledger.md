## Dependency decision

Runtime and tests use only pinned **Deno 2.9.0** Web APIs and local modules. There are no
third-party imports, so `deno.lock` contains no remote package graph. `deno info` is named and used
as a dependency-graph check; `deno audit` is the vulnerability audit. The cached MCP SDK inspection
above is reference evidence only and does not alter the empty dependency graph. The CI runtime is
exact-pinned.

## Release blockers (fail closed)

1. Exact stable official TypeScript SDK version/API and modern+legacy conformance.
2. Named MCP client compatibility.
3. Deno Deploy v2 database/KV availability, atomic CAS semantics, retention, backup, and limits.
4. Nango callback state/PKCE/exact redirect/authenticated completion behavior.
5. Nango separate least-privilege key scopes with no credential read/list/admin.
6. Nango proxy redirect behavior.
7. GitHub issuer behavior and final OAuth app settings.
8. Paul decisions and independent gates in `docs/reviews/stage0-gates.md`.
